# Qué es un proxy?
Un **proxy** actúa como un intermediario entre nuestro navegador y el servidor. Esto nos permite muchas cosas, desde detener la petición, analizar sus cabeceras, modificar parámetros y tambien analizar las request. Ademas de eso, podemos usar mas herramientas como lo son el repeater y dependiendo del proxy que utilicemos otras funciones más (como algun iterador de algun parámetro como el caso de calido). 
La diferencia con la vpn esta en que la vpn redirige todo el tráfico para ocultar nuestra IP real (y con esto otros datos como el proveedor de internet por ejemplo) y modificarla por una de nuestro interes. No esta destinada al analisis de cada peticion o respuesta, analiza todo a nivel mas global si se quiere.
