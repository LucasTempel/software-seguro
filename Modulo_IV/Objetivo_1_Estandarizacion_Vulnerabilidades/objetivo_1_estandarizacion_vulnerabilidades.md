## CVE (Common Vulnerabilities and Exposures)
El CVE funciona como un catálogo de fallas de seguridad que ya fueron descubiertas y confirmadas. Le asigna un identificador único a una vulnerabilidad específica en un producto o software concreto.

## CWE (Common Weakness Enumeration)
Por otro lado, el CWE es más bien una lista o diccionario que clasifica las debilidades a nivel de arquitectura, diseño o código del software y hardware. Osea, por cada CWE existen multiples CVE.
UN ejemplo de CWE podria ser Inyeccion SQL.

## Autoridades de asignación y consulta (CNAs)
Los identificadores CVE son gestionados por los **CNAs (CVE Numbering Authorities)**, que son organizaciones autorizadas para numerar y publicar estas vulnerabilidades.

Una vez que se publican, estos reportes se pueden consultar de forma libre y pública en bases de datos como: El sitio web oficial de ``Mitre``.

## Herramientas automatizadas de la industria
Para detectar si los sistemas de una empresa tienen versiones de software afectadas por CVEs conocidos, se utilizan escáneres de vulnerabilidades automatizados. Dos de los más populares son:
1. **Nessus:** Utilizada para auditorías de red.
2. **OpenVAS (Greenbone):** Es la alternativa de código abierto por excelencia.
